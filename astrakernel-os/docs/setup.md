# AstraKernel OS Setup
Instructions for preparing your environment to build AstraKernel OS.

1. Ensure you have a standard Debian/Ubuntu machine.
2. Install the necessary dependencies for building a Live ISO:
    sudo apt install debootstrap squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools
3. Clone or download this project zip and extract it.
4. Mark the scripts as executable: chmod +x *.sh
