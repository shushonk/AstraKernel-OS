# Roadmap

Future capabilities for AstraKernel OS:
- Custom package manager wrapper (`astrabrew`)
- Custom app store application
- Web dashboard (similar to Umbrel)
- System updater utility
- Custom settings GUI app
- Cloud sync (Nextcloud integration)
- Local AI assistant
- Dedicated Developer mode toggle
- Cybersecurity toolkit tier
- Theme switcher
- Graphical Installer (`Calamares` integration)
